# Best-times-to-visit research drafts

Raw research material for `country_guides.best_times`, gathered 2026-09-02 via
web search (one query per country, "best time to visit {country}" — see
[best-time-research-query-scope](../../../.claude memory, or forin-scratch-notes.md)
for why the query is phrased that way, not weather-scoped).

**This is a draft, not published content.** Per the Tier B pattern in
CLAUDE.md's External Data Sources section, these notes are a starting point
for a human rewrite — `why_short`/`why` should end up in your own words,
informed by this research rather than copied from it.

- `best_times_draft.csv` — country_code, country_name, source_method, draft_notes
  (221 countries; source_method flags the 44 redone after the initial
  weather-scoped-query pass was corrected)
- `best_times_flagged.csv` — 6 countries skipped as genuine no-tourism
  destinations (uninhabited or access-restricted territories), not failures

Scope: all countries except the 23-country "US-L4" skip list (US State Dept
Level 4 advisories) — see forin-scratch-notes.md's Odds and ends section.

Gitignored — this is working material, not canonical project data.
